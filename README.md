📈 Monitor de Câmbio: Dólar Americano (USD/BRL)
Este projeto consiste em um dashboard interativo desenvolvido no Power BI que consome dados em tempo real da API do Banco Central do Brasil para monitorar a cotação do dólar.

🚀 Funcionalidades
Conexão Dinâmica: Extração automatizada de dados via API REST (SGS - Sistema Gerenciador de Séries Temporais).

Análise Temporal: Gráfico de linhas permitindo a visualização da tendência histórica da moeda.

KPIs em Tempo Real: Cartão dinâmico exibindo a cotação mais recente (Dólar Hoje).

Visão Gerencial: Gráfico de rosca detalhando a média de cotação por trimestre (Qtr), facilitando a análise de sazonalidade.

Interatividade Total: Filtros de data (Slicer) e filtragem cruzada entre todos os elementos visuais.

🛠️ Tecnologias e Técnicas Utilizadas
Power Query (M): Tratamento de dados, conversão de tipos e limpeza de séries temporais.

DAX (Data Analysis Expressions): Criação de medidas para cálculo de média móvel e identificação do último valor registrado.

UI/UX Design: Implementação de Dark Mode com transparência em camadas para uma interface limpa e moderna.
